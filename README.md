# Robust Credit Allocation

Simulation code for the paper *Policy Learning under Distribution Shift with
Infinite-Dimensional Policy Classes: An Application to Consumer Credit Allocation*.
The repository contains data generation, policy learning, evaluation and result
aggregation code.

## Requirements

The code was tested with Python 3.8.20, NumPy 1.24.1, pandas 1.5.3,
SciPy 1.10.1 and PyTorch 2.3.0+cu118.

```bash
python -m pip install torch==2.3.0 --index-url https://download.pytorch.org/whl/cu118
python -m pip install -r requirements.txt
```

CUDA is used when available; otherwise the script uses the CPU.
Run the commands below from the repository root.

## Repository structure

```text
run_simulation.py             Experiment settings and execution
simulation/
  dgp.py                     Generate training, validation and test samples
  shift.py                   Generate covariate-shift and concept-drift environments
  experiment.py              Fit policies, select widths and aggregate results
  random_inputs.npz          Fixed random seeds and bootstrap draws
policy_core/
  models.py                  Policy networks
  learning.py                Policy-learning routines
  evaluation.py              Validation and OOB selection
  robust_values.py           KL-robust policy-value calculation
```

## 1. Generate simulation data

Data are generated automatically by `simulation/dgp.py` during each run.
Each replication uses 4,500 training observations, 500 validation observations
and 2,500 test observations. No dataset download or separate generation command
is required.

- **Baseline experiment:** four independent covariates are drawn uniformly from
  [-1, 1]. The Low, Middle and High cases use different complexities of the
  action-response boundary. Potential outcomes are generated by a logistic
  transformation with shared Gaussian noise of standard deviation 0.6. Each
  logged action has probability 0.5. Independent validation and test samples
  are generated for width selection and evaluation.
- **Distribution-shift experiment:** the Middle case's covariates and logged
  actions are paired with a continuous lower-tail outcome model. The outcome
  model therefore differs from the baseline experiment. `simulation/shift.py`
  generates covariate shifts by reweighting and resampling covariates, and
  concept drift by changing the conditional probability of a low outcome.
  Each severity uses 100 paired environments for the two methods.

`simulation/random_inputs.npz` supplies the fixed seeds and bootstrap draws;
the observations and outcomes are generated by the code, not loaded from that
file. Keep this file with the source code.

## 2. Run the experiments

Set the variables below in `run_simulation.py` for the desired experiment.
The reported experiments use replications 0--99. Use `REPLICATIONS = [0]` to run
one replication instead.

### (1) Policy complexity: Low, Middle and High

```python
MODE = "experiment"
STUDY = "baseline"
CASES = ["low", "moderate", "high"]
REPLICATIONS = list(range(100))
OUTPUT_FOLDER = "results/baseline"
```

```bash
python run_simulation.py
```

### (2) Robustness under distribution shift

```python
MODE = "experiment"
STUDY = "shift"
CASES = ["moderate"]
REPLICATIONS = list(range(100))
OUTPUT_FOLDER = "results/shift"
```

```bash
python run_simulation.py
```

This run includes both robust and non-robust policies under covariate shift and
concept drift. The severity grid is 0, 2, 4, 6, 8, 10 and 12; the reported table
uses 0 through 10.

The default `MODE = "fit"` trains one Low-case model at width 10. Use
`MODE = "experiment"` for the full width grid, policy selection and evaluation.
Choose a new `OUTPUT_FOLDER` for each run.

## 3. Aggregate results

Results are aggregated automatically at the end of each experiment:

```text
results/baseline/summary.csv
results/shift/summary.csv
```

Each output folder also contains `selections.csv` and `replication_results.csv`.
The shift experiment writes `environments.csv` with environment-level results.
Fitted models and training losses are saved as `model.pt` and `training.csv`
under the corresponding case, replication, method and width subdirectories.
