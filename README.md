# Robust Credit Allocation

Simulation code for the paper *Policy Learning under Distribution Shift with
Infinite-Dimensional Policy Classes: An Application to Consumer Credit Allocation*.

## Requirements

Tested with Python 3.8.20, NumPy 1.24.1, pandas 1.5.3, SciPy 1.10.1 and
PyTorch 2.3.0+cu118.

```bash
python -m pip install torch==2.3.0 --index-url https://download.pytorch.org/whl/cu118
python -m pip install -r requirements.txt
```

Run commands from the repository root. CUDA is used when available; add
`--device cpu` to use the CPU.

## Repository structure

```text
run_simulation.py     Command-line entry, experiment workflow and aggregation
dgp.py                Sample generation and distribution shifts
learning.py           Policy network and training
evaluation.py         Robust policy values and OOB selection
random_inputs.npz     Fixed random seeds and bootstrap draws
```

## 1. Generate simulation data

Each replication contains 4,500 training, 500 validation and 2,500 test
observations. The baseline cases use four Uniform(-1,1) covariates,
logistic-transformed noisy outcomes and equally probable logged actions. The
Low, Middle and High cases vary the action-response boundary complexity.
The shift experiment uses the Middle covariates and actions with a continuous
lower-tail outcome model. Covariate shift resamples covariates; concept drift
changes conditional low-outcome probabilities. Observations are generated by
the code using the fixed random inputs.

### Baseline cases

```bash
python run_simulation.py --mode generate --study baseline --cases low moderate high --num-reps 100 --data-dir data
```

Use `--cases low`, `--cases moderate` or `--cases high` to generate one case.

### Covariate shift and concept drift

For each `LEVEL = 0, 2, 4, 6, 8, 10`, substitute the value in these commands:

```bash
python run_simulation.py --mode generate --study shift --shift-mode covariate --level LEVEL --num-reps 100 --data-dir data
python run_simulation.py --mode generate --study shift --shift-mode concept --level LEVEL --num-reps 100 --data-dir data
```

Alternatively, generate both types and all reported levels in one command:

```bash
python run_simulation.py --mode generate --study shift --shift-mode both --level 0 2 4 6 8 10 --num-reps 100 --data-dir data
```

Each level contains 100 environments per replication. Existing generated files
are reused, including the common training samples. Level 12 is also available
as an additional setting.

Samples are saved under `data/STUDY/CASE/rep_NNN/samples.npz`. Shift environments
are saved alongside them: `covariate_level_LEVEL.npz` contains resampling
indices, and `concept_level_LEVEL.npz` contains potential outcomes.

## 2. Run the experiments

Training reads the files generated above. Each command evaluates the fitted
policies and writes replication-level results and a summary.

### Policy complexity: Low, Middle and High

```bash
python run_simulation.py --mode run --study baseline --cases low moderate high --num-reps 100 --data-dir data --output results/baseline
```

### Robustness under distribution shift

```bash
python run_simulation.py --mode run --study shift --shift-mode both --level 0 2 4 6 8 10 --num-reps 100 --data-dir data --output results/shift
```

This fits robust and non-robust policies once per replication and evaluates
them at every requested level. Use `--shift-mode covariate` or `concept` and
`--level LEVEL` to evaluate a subset instead.

### Small runs

Generate one replication and train one model:

```bash
python run_simulation.py --mode generate --study baseline --cases low --num-reps 1 --data-dir data
python run_simulation.py --mode fit --study baseline --cases low --num-reps 1 --width 10 --method robust --data-dir data --output results/one_model
```

For a complete single-replication experiment, use `--mode run --num-reps 1`.
Use `--start-rep N --num-reps M` to run a consecutive subset of replications
0--99. Choose a new output folder for each training run.

## 3. Aggregate results

Summaries are created automatically. To regenerate them from saved results:

```bash
python run_simulation.py --mode summarize --study baseline --output results/baseline
python run_simulation.py --mode summarize --study shift --output results/shift
```

Output files are `selections.csv`, `replication_results.csv` and `summary.csv`.
The shift experiment also saves `environments.csv`. Each candidate directory
contains `model.pt` and `training.csv`.
